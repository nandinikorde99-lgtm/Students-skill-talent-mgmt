# Students Skill & Talent Management System

An OOP-based college mini project divided into 5 modules.

## Modules
1. Login & Registration
2. Student Profile & Management
3. Skill Management
4. Admin Dashboard
5. Event & Competition Management

The design demonstrates the four OOP pillars:
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

## Language
Java

## Run
Open the project in IntelliJ IDEA / Eclipse / VS Code with Java installed.
Compile and run `Main.java` files.
